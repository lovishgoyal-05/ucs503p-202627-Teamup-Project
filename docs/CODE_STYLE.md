# Code formatting

This archive has been reformatted for readability. Java classes use consistent indentation and block/statement line breaks; JSON is pretty-printed; CSS declarations are separated onto readable lines; SQL statements are separated; and JS/JSX statements are lightly line-broken without changing JSX structure.

Formatting is not a substitute for compiling or running tests. Please run `mvn test` in `backend/` and `npm run build` in `frontend/` after installing dependencies.
